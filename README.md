# Oddsnytt Hub

Create a modern, fast, and SEO-optimized sports news and betting tips website for the domain oddsnytt.com using Astro, React, and Tailwind CSS.

Build a clean, dark-themed grid layout tailored for sports articles, match predictions, and betting content, keeping standard folder structures (/public for assets and /src for components/pages). This initial build is a placeholder framework, as I will be integrating my colleague's custom prompt logic and existing setup from GitHub directly after initialization.

This project was built with [Lovable](https://lovable.dev).
